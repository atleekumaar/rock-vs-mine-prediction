 Rock vs Mine Prediction

This project uses Machine Learning to predict whether a detected object is a Rock or a Mine based on SONAR data.

  Tech Stack & Libraries
- Python 3
- NumPy
- Pandas
- Scikit-learn (Logistic Regression)

  Dataset Details
- Dataset: SONAR Dataset
- Features:60 numerical sonar frequencies
- Target:Class 'R' for Rock, Class 'M' for Mine

 Model Performance
- Training Accuracy:~83.4%
- Test Accuracy:~76.1%
